# Happy wash — demo website

Single-file static demo site for **Happy wash**, a hand car wash and detailing service in the Suomenoja/Friisinmäki area of Espoo (Hannuksenpelto 2B, 02270 Espoo).

Everything (HTML, CSS, JS) lives in `index.html`. The only external resources are one Google Font and Unsplash photos.

## How to open

Double-click `index.html`, or serve the folder statically, e.g. `npx serve .` or `python -m http.server`.
